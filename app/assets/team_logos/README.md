This folder now contains a vendored MLB logo set used by the Streamlit app.

Place local MLB team logo files in this folder to replace any existing assets.

Supported filenames use the ESPN/slug convention below:

- `ari`
- `atl`
- `bal`
- `bos`
- `chc`
- `chw`
- `cin`
- `cle`
- `col`
- `det`
- `hou`
- `kc`
- `laa`
- `lad`
- `mia`
- `mil`
- `min`
- `nym`
- `nyy`
- `oak`
- `phi`
- `pit`
- `sd`
- `sf`
- `sea`
- `stl`
- `tb`
- `tex`
- `tor`
- `wsh`

Examples:

- `app/assets/team_logos/lad.svg`
- `app/assets/team_logos/nyy.png`

Supported extensions:

- `.svg`
- `.png`
- `.webp`
- `.jpg`
- `.jpeg`
